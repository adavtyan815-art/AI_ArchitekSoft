## 📖 Ինչպե՞ս սկսել աշխատանքը նոր չաթում

Եթե բացել եք նոր չաթ, խնդրում ենք առաջին հերթին կարդալ ամբողջական նախագծային փաստաթուղթը՝
👉 **[`docs/PROJECT_CONTEXT.md`](docs/PROJECT_CONTEXT.md)**

Այնտեղ մանրամասն շարադրված է՝
* Ընկերության էությունը և պրոդուկտի 4 փուլերը (Էսքիզ $\rightarrow$ UE5 4K $\rightarrow$ Web/AR $\rightarrow$ Ռասկրոյ PDF)
* Բրենդի ռազմավարությունը (B2B տեխնոլոգիական հեղինակություն և պրեստիժ)
* Արդեն պատրաստի կոդը (`dashboard/`, `media_library/`, `website/`)
* Հաջորդ կատարվելիք քայլերը
